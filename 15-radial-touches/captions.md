tap-pitch: Tapping the pitch in focus mode no longer opens the full-screen "Record Player Action" form; an action ring (Attack, Defend, Duel, More) appears at the tap point instead.
outcome-ring: Choosing an action (here Pass) swaps in an outcome ring with that action's outcomes and a Back segment; one more tap saves the touch.
edit-ring: Tapping an existing marker opens the same rings in edit mode, with the current action outlined and Delete, Minute, Move and More in an Edit group.
